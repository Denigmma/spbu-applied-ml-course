# Прикладные задачи машинного обучения: домашние задания

Мурадян Денис

Каждое задание лежит в отдельной ветке, отходящей от `main`, и сдаётся через Pull Request.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

Датасеты скачиваются внутри ноутбуков через `kagglehub`, отдельно ничего качать не нужно. На Kaggle ноутбук берёт датасет из `/kaggle/input`, если он подключён как input.
